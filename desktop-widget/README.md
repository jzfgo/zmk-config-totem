# Desktop cheatsheet widget

Shows `totem-keymap-cheatsheet.svg` on the desktop, between the wallpaper and the windows. It
is an [Übersicht](https://tracesof.net/uebersicht/) widget with frosted-glass keys that
follow the current wallpaper, including rotating ones.

The repo SVG (generated by `tools/totem_cheatsheet.py`) is left untouched. The widget reads
it on every refresh and re-lays it out for
the screen. It keeps the four working layers (BASE, NAVI, SYM, ADJ) in a 2×2 grid spaced to
the display's proportions, puts each layer name on a pill, and drops the title, the
captions, the notes and LEARN.

## Install

```sh
brew install --cask ubersicht
./desktop-widget/install.sh
```

Then pick the display from Übersicht's menu bar icon (`totem-cheatsheet` → screen) and enable
*Launch Übersicht when I log in*. Re-run `install.sh` after changing anything here.

## Files

| File | What it does |
|---|---|
| `index.jsx` | The widget. It re-lays out the SVG, adds the frosted glass, and holds the styling (key tint, legend opacity, pill colours) plus the keyglow client. Tunables sit at the top: `GAP_X`, `GAP_Y`, `MARGIN`, `BLUR`, `PILL_*`. |
| `wallsnap.swift` | Snapshots the wallpaper window with ScreenCaptureKit (~0.3 s). It only rewrites `wall.jpg` when the wallpaper actually changes, so the 5 s poll costs almost nothing. It needs Screen Recording permission for Übersicht. Without it the keys are plainly translucent. |
| `keyglow.swift` | Optional. Lights the keys you press (see below). |
| `install.sh` | Builds the helpers into the widget folder and installs `index.jsx` pointing at this checkout's SVG. |

The widget re-layout depends on how the SVG is drawn: layer names are 19px `a-*` texts,
keys are `rect.k`/`.off`/`.none`, and captions are `.muted`. Keep that in mind if the SVG
generator changes.

## keyglow (parked)

`keyglow` makes the pressed key glow in its layer's colour. A listen-only event tap
translates each press into the labels on the sheet, using the active macOS layout, and
streams them as Server-Sent Events on `127.0.0.1:41427`. Only the Übersicht origin can
read the stream, and only with a per-run token (`keyglow.token`, mode 0600).

It is not installed by default (`install.sh --with-keyglow` builds it but does not start
it) because it is a keystroke stream:

- Web pages and sandboxed apps can't read it, but any unsandboxed process running as your
  user could read the token.
- Terminals like kitty don't enable Secure Input, so a `sudo` password typed there goes
  through the stream.
- macOS only sees characters, not layers. A character drawn on several layers (e.g. `{`)
  lights all of them, and holding the layer thumbs (TAB/ESC) sends nothing.

It needs Input Monitoring permission. Run it with a LaunchAgent so the permission is granted
to the `keyglow` binary itself, not to your terminal.
